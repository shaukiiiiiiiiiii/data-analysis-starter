# Data Analysis Starter

A small Jupyter notebook starter for Python data analysis. It includes commonly
used libraries for working with tabular data and creating visualizations.

## What's included

- `data-analysis-starter.ipynb` — notebook scaffold with NumPy, pandas,
  Matplotlib, and Seaborn imports.
- `requirements.txt` — Python dependencies, including Jupyter.

The notebook currently contains imports only. Add your dataset, analysis, and
visualization cells to build on it.

## Getting started

You will need Python 3. Create and activate a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Install the dependencies and start Jupyter:

```powershell
python -m pip install -r requirements.txt
jupyter notebook
```

Open `data-analysis-starter.ipynb` in Jupyter or in VS Code with the Jupyter
extension installed.

## Dependencies

- NumPy
- pandas
- Matplotlib
- Seaborn
- Jupyter
